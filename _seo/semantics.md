Дальнейший контент отбирать по запросам и посадочным Яндекс.Вебмастера, затем сверять спрос в Wordstat. Не создавать пустые комбинации района, комнат и цены без подтверждённых лотов. У каждой страницы собственная задача; фильтр каталога не создаёт индексируемые URL.

Технический контроль: production robots разрешает обход, карты содержат канонические URL, все посадочные пререндерены в HTML. Хлебные крошки BreadcrumbList, Article для материалов, CollectionPage/ItemList для подборок, ApartmentComplex для ЖК без вымышленных offers/рейтингов.

Операционные зависимости: подтвердить сайт в Вебмастере, отправить sitemap и проверить регион Москва. Нужен реальный ID Метрики; случайный счётчик не устанавливать. Юридические реквизиты, офис и график добавлять только после подтверждения владельца. Сертификат HTTPS и переключатель Enforce HTTPS зависят от Pages/DNS; диагностика добавлена в deployment workflow. Текущий рабочий origin: http://main-hall.ru. Диагностика Pages: https_certificate=null, HTTP 200, HTTPS hostname mismatch. Все canonical и sitemap временно указывают на доступный HTTP. После выпуска сертификата: заменить SITE_URL, metadataBase, базу notify-indexnow.py и ожидание в SEO-тесте на HTTPS, обновить метаданные коммерческой страницы и включить Enforce HTTPS для постраничного 301. IndexNow отправляется для текущего рабочего origin.
